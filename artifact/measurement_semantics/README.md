# Evaluated measurement-semantics instance

The manuscript studies an alignment mechanism and bounds its measured evidence to one software stack. These files identify the historical instance:

- `sdk_versions.json`: observed evaluated packages, native binary/instrumentation hashes, and scope limits.
- `source_locations.json`: pinned public source locations and reference-code identity.
- Root `PROVENANCE.json`: retained source digests and the boundary of the public derived-data release.

The public source commit is not an independently verified exact build identity for the installed wheel. Native arithmetic agrees with the pinned-source replay for the examined path. Native testing used a temporary transport-instrumented copy; original installation and trust settings remained unchanged.

Full raw/native re-execution is not supported by this public bundle because original joint shots, private calibration snapshots and compiled SDK binaries are excluded. The public scripts reproduce arithmetic from derived tables and a synthetic example. A reference-order check is conventional linear algebra, not a claim of a novel mitigation algorithm, physical accuracy improvement or widespread failure in other SDKs. Maintainer intent remains unconfirmed. Upstream issue publication is deferred.
